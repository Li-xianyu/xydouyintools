# xyDouYinTools

让视频当主角，界面少打扰。

抖音网页版沉浸式增强工具，提供 **Chrome 扩展**和**油猴脚本**两种安装方式。主功能共用一套源码；摄像头手势控制是可选的独立脚本。

## 功能

- **沉浸观看**：调整视频展示区域，左侧导航、顶栏、播放器控制栏和交互区在鼠标靠近时显示。
- **两种材质**：磨砂与液态玻璃可切换，支持主题色、居中搜索胶囊和顶栏入口独立开关。
- **浮动面板**：评论区可拖动、缩放、记忆位置，也可固定在右侧为视频留出空间；适配消息、通知、章节等弹窗。
- **界面细节**：优化搜索、右键菜单、播放器弹出菜单，以及推荐、购物入口的样式和显隐。
- **鼠标操作**：左右划动、中键、长按等常用操作；右键菜单可直接进入工具设置。
- **内容过滤**：可配置直播跳过、关键词和作者过滤。默认带有部分关键词示例，可在设置里调整。
- **图文提取**：长按当前图片生成悬浮小图，可拖动、保存，或尝试拖到网页之外。
- **可选摄像头控制**：挥手切视频、张掌开关评论、摇头发送不感兴趣、微笑点赞，详见[手势控制说明](docs/gesture-control.md)。

主要适配抖音网页视频流。抖音会调整页面结构，部分功能可能因页面类型、账号实验或浏览器差异而表现不同。

## 安装

### Chrome 扩展

1. 下载本仓库并解压，或使用 Git 克隆：

   ```bash
   git clone https://github.com/Li-xianyu/xydouyintools.git
   ```

2. 在 Chrome 打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目根目录。
4. 打开或刷新抖音网页。点击扩展图标或按 `Alt + X` 打开页面内设置。

仓库包含扩展所需的样式载荷，直接加载即可，无需先安装 Node.js 或运行构建。

### 油猴脚本

安装支持 UserScript 的脚本管理器，然后打开本仓库的原始脚本地址：

- [安装主脚本](https://raw.githubusercontent.com/Li-xianyu/xydouyintools/main/xyDouYinTools.user.js)
- [安装可选的摄像头手势脚本](https://raw.githubusercontent.com/Li-xianyu/xydouyintools/main/xyDouYinTools.gesture.user.js)

如果原始地址没有出现安装提示，可把对应文件导入脚本管理器。主脚本元数据中的自动更新地址指向 Greasy Fork，GitHub 文件用于源码分发及手动安装。

**主扩展和主油猴脚本选择一种运行即可**，同时启用会让两份主程序重复介入页面。独立手势脚本可以和任意一种主版本配合使用。

## 常用操作

| 操作 | 用途 |
| --- | --- |
| `Alt + X` | 打开或关闭设置 |
| `Alt + H` | 切换全部界面显示，便于查看被自动收起的组件 |
| 鼠标靠近左侧、顶部、底部或右侧 | 显示对应区域的组件 |
| 右键视频 | 打开美化后的菜单，顶部提供设置入口 |
| 长按图文图片 | 提取为悬浮图片，需开启相关功能 |
| `Alt + G` | 开启或停止摄像头，仅独立手势脚本提供 |

设置会在当前浏览器中保存。扩展与主油猴版本使用各自的设置环境；更换浏览器或配置目录后不一定保留原来的设置。

## 开发

日常修改 `src/` 下的源码，不直接编辑根目录的两份发布脚本。主版本使用 Python 3 合并：

```bash
python merge.py
```

这个命令沿用现有主脚本版本；发布新版本时传入版本号。独立手势脚本不经过主脚本合并，详细流程见[开发说明](docs/development.md)。

## 摄像头与外部资源

摄像头功能使用 Google **MediaPipe Tasks Vision 0.10.21** 的手部与面部模型。开启后需授权摄像头；识别在本机浏览器 Worker 中进行，脚本不会把摄像头画面上传给识别服务。首次使用需要联网下载库、WASM 和模型，之后优先使用浏览器缓存。抖音页面和脚本管理器自身仍有各自的网络行为。

## 反馈

提交问题时，建议附上：安装方式、脚本版本、浏览器版本、复现步骤，以及不包含私人内容的截图。与某个视频有关时，可附公开视频链接，方便定位不同类型的播放器和角标。

第三方库与模型遵循其上游许可；本项目脚本元数据标注的许可为 MIT。
