# 摄像头手势控制

这是 xyDouYinTools 的可选独立油猴脚本，安装文件为根目录的 [`xyDouYinTools.gesture.user.js`](../xyDouYinTools.gesture.user.js)，源码位于 [`src/standalone/`](../src/standalone/)。

## 使用

1. 安装脚本后刷新抖音网页，打开手势控制面板。
2. 点击「开启摄像头」，首次使用时允许摄像头权限，并等待识别资源加载。
3. 选择自动、左手或右手控制，按需要开启各项功能。
4. 使用 `Alt + G` 开启或停止；窗口失焦时脚本会停止摄像头。

## 手部控制

| 动作或选项 | 用途 |
| --- | --- |
| 半握并伸出食指，上下挥动 | 切换视频，可反转方向 |
| 向左挥动 | 发送 Z，对应抖音点赞快捷键 |
| 向右挥动 | 发送 R，对应抖音不感兴趣快捷键 |
| 完整张掌并短暂停留 | 开关评论区，配合主工具时复用评论面板入口 |
| 挥动方向开关 | 上、下、左、右独立启用，关闭的方向不触发对应手势 |
| 忽略手背 | 尝试过滤背对摄像头的手；侧面和遮挡可能影响判断 |
| 左右手反转 | 模型识别的左右手与实际使用不符时调整 |
| 虚拟拖动 | 在页面中显示跟手指示点，尝试原生拖动翻页，未确认切换时再回退 |

上下手势按画面中手掌的大小调整幅度，距离摄像头较远时所需位移也相应缩小。挥动后保留回程和停稳保护，减少放下手时反向切回视频的情况。

网页合成事件可能受抖音自身的处理方式限制，识别到动作不等于页面一定接受操作。输入框、模态弹窗、切换过程等状态也可能暂停动作发送。

## 面部控制

两项功能独立开关，默认关闭；只有启用面部功能时才按需加载面部模型。

### 摇头 R

先正脸保持片刻完成方向校准，再左右摇头。无需撇嘴；符合条件时发送一次 R，并保留约 4 秒冷却。

### 微笑点赞

- 当前普通模式的微笑触发分数为 2%，低于约 1% 时进入停止判断，并辅以嘴部关键点形态判断。
- 首次识别到持续微笑，在当前视频画面中心双击。
- 持续微笑时，在画面中央 60% 的区域随机选择 10 个位置，依次双击，每次间隔 100 毫秒。
- 停止微笑、切换视频、停止摄像头或关闭开关，会中止后续发送。
- 双击后读取原生点赞状态；明确处于未点赞状态时尝试原生赞按钮兜底，避免反复取消点赞。

模型分数是识别结果，不是人的微笑程度或准确率百分比。较低门槛更容易触发，也可能把自然表情误判为微笑。

## 识别调节

- **挥动距离**：越低越灵敏。
- **识别帧率**：可设 5～60 FPS，新设置默认目标为 30；已有设置保持不变。
- **激进模式**：降低挥动幅度、速度、手指伸直程度、就绪和收手等待门槛，同时放宽部分面部动作条件；保留回程保护，可能增加误触。

帧率标签的「实际」指每秒完成识别的次数，并不是摄像头出图速度。鼠标悬停帧率数字，可查看摄像头协商帧率、手部与面部推理耗时、取帧耗时，以及 CPU/GPU 后端。

脚本会优先尝试 GPU，初始化失败后回退 CPU；脸部检测按耗时调整频率，降低与手势争用计算时间的程度。实际速度仍受设备、浏览器、模型与抖音页面负载影响。

## 预览

- 双击摄像头预览，切换小窗与完整面板；小窗可拖动。
- 小窗不显示状态文字；状态统一放在完整面板的手势状态栏。
- 「手部骨架」「面部骨架」「辅助横条」三个显示开关独立保存。
- 右键预览可统一显隐骨架与横条，只停止绘制，不停止识别；恢复时沿用各项独立显示设置。

## 外部资源与隐私

使用 Google MediaPipe Tasks Vision 0.10.21、Hand Landmarker 和 Face Landmarker。库、WASM 与模型首次需联网获取，下载后缓存在当前浏览器的 IndexedDB 中；面部模型仅在需要时下载。

摄像头图像在本机浏览器中处理，脚本不向识别服务器上传视频帧，也不进行人脸身份识别。更换配置目录、清理站点数据或缓存损坏后，可能需要重新下载资源。
